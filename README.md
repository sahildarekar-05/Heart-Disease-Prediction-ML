# Heart Disease Prediction using Machine Learning

## Project Overview
This project predicts whether a patient is likely to have heart disease using Machine Learning algorithms.

The project includes:
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Feature Selection
- Outlier Handling
- Model Training
- Ensemble Learning

## Dataset
UCI Heart Disease Dataset imported from OpenML.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- OpenML

## Machine Learning Models
- Logistic Regression
- Random Forest
- SVM
- AdaBoost
- Gradient Boosting
- Decision Tree
- Voting Classifier

## Workflow
1. Data Collection
2. Data Cleaning
3. EDA
4. Feature Engineering
5. Feature Scaling
6. Model Training
7. Prediction

## Sample Output
Prediction:
- 0 → No Heart Disease
- 1 → Heart Disease Detected
